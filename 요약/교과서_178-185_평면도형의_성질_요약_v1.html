[중1 2학기 중간대비] 교과서 핵심 요약집 — 6. 평면도형의 성질 (p.178~185)

[단원 성취 기준] 다각형에서 대각선의 개수를 구하는 과정을 논리적으로 유도하고 설명할 수 있으며, 삼각형의 내각과 외각 사이의 관계를 이해하여 다양한 기하학적 문제 해결에 능숙하게 적용한다.
1. 단원 도입 및 초등 연계 기초 점검 (6.0 / 교과서 p.178~179)
• 실생활과 예술 속 평면도형: 알람브라 궁전의 벽면과 기둥을 장식한 테셀레이션(타일 무늬) 속에서 다각형의 대칭과 반복 구조를 발견함.
• 초등 연계 기초 점검 3요소: ① 다각형의 뜻: 선분으로만 둘러싸인 평면도형 (곡선·입체 제외)  |  ② 내각의 합 기초: 삼각형 = 180°, 사각형 = 360°
③ 원 기초: 원의 둘레(원주) = 2πr, 원의 넓이 = πr2
2. 다각형의 대각선의 개수 (6.1 / 교과서 p.180~182)
• 다각형(Polygon): 3개 이상의 선분으로 둘러싸인 평면도형 (n개의 변 ➔ n각형)
• 정다각형: 모든 변의 길이가 같고, 모든 내각의 크기가 같은 다각형 [함정] (둘 중 하나만 만족하면 절대 정다각형 아님!)
• 대각선(Diagonal): 다각형에서 이웃하지 않는 두 꼭짓점을 이은 선분 [주의] 삼각형은 대각선이 0개임.
(1) 대각선 공식 유도 원리
• 한 꼭짓점 대각선 수: [공식] n - 3 (개)
  – 원리: 자기 자신(1개)과 양옆의 이웃 꼭짓점(2개)을 뺀 3개 제외.
• 나뉘는 삼각형 개수: [공식] n - 2 (개)
  – 원리: 대각선 1개 그을 때마다 삼각형 1개씩 추가됨.
(2) [빈출] n각형 대각선의 총 개수 공식
n각형 대각선의 총 개수 = n(n - 3) 2 (개)
• 원리: n개 꼭짓점에서 각각 (n-3)개씩 그을 수 있으나, 한 선분의 양 끝점에서 2번씩 중복 계산되므로 2로 나눔.
[도형 1] 오각형 대각선 2개(5-3), 삼각형 3개(5-2)
(3) 교과서 탐구 및 실전 심화 4대 유형 클리닉 (p.181~182)
① 대각선으로 다각형 분할 (p.181 생각 넓히기)
• 문제: 한 꼭짓점 대각선으로 사각형과 육각형으로 나뉨.
• 원리: 분할된 두 다각형의 변의 합에서 공통 대각선 2개 차감 ➔ 4 + 6 - 2 = 8 (팔각형)
• 대각선 총 개수: 8 × 52 = 20개 		② 대각선 수로 다각형 이름 찾기 (p.182 4번)
• 문제: 대각선의 총 개수가 65개인 다각형의 이름은?
• 풀이: n(n - 3)2 = 65 ➔ n(n - 3) = 130
  연속한 두 자연수 곱: 13 × 10 = 130 ➔ 십삼각형 (n = 13)
③ 악수(네트워크) 횟수 구하기 (p.182 5번 연결)
• 문제: 11명이 빠짐없이 서로 한 번씩 악수하는 총 횟수는?
• 풀이: 꼭짓점 11개인 다각형의 (변의 수 + 대각선 수)
  총 악수 횟수 = 11 × 102 = 55번 		④ [함정] 두 꼭짓점 대각선 합 (p.182 6번 도전)
• 문제: 이웃하지 않는 두 점에서 그은 대각선 총합이 7개.
• 핵심: 두 점 사이의 공통 대각선 1개 중복 차감!
  (n - 3) + (n - 3) - 1 = 7 ➔ 2n = 14 ➔ 칠각형 (n=7, 총 14개)
3. 삼각형의 내각과 외각 (6.2 / 교과서 p.183~185)
• 내각과 외각의 정의: 다각형 내부의 각을 내각, 한 변과 이웃한 변의 연장선이 이루는 각을 외각이라 함.
• 기본 관계: 다각형의 한 꼭짓점에서 내각 + 외각 = 180° (맞꼭지각이므로 2개의 외각 크기는 서로 같음)
• [빈출] 삼각형 외각의 핵심 정리: 삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같다.
(1) 외각 성질의 평행선 증명 (p.184)
[도형 2] 엇각(●)과 동위각(×)에 의한 외각 증명
• AB // CE에서 ∠ACE = ∠A (엇각), ∠ECD = ∠B (동위각)
➔ ∠ACD = ∠A + ∠B
(2) [함정] 사각형 외각 오개념 정복 (p.184 생각 넓히기)
• 질문: 사각형의 외각은 이웃하지 않는 세 내각의 합과 같을까?
• 판정: 절대 아니다! (오답)
• 이유: 사각형 내각의 총합은 360°이므로,
  – (이웃하지 않는 세 각의 합) = 360° - ∠C
  – (한 꼭짓점의 외각) = 180° - ∠C
  – 두 식의 값이 서로 다르므로 사각형에는 적용 불가!
• 결론: '한 외각 = 두 내각의 합'은 오직 삼각형에서만 성립함!
(3) 교과서 해결해요 시험 빈출 4대 기하 실전 모델 (p.185)
모델 1. 맞꼭지각/나비넥타이 모델 (3번 (1))
• 맞꼭지각 크기가 같으므로: ∠A + ∠B = ∠C + ∠D
• 예시: 55° + 30° = 60° + x ➔ x = 25° 		모델 2. 부메랑(오목 사각형) 모델 (4번)
• 보조선 외각 성질: ∠x = ∠a + ∠b + ∠c
• 예시: 80° + 20° + 25° ➔ ∠x = 125°
모델 3. [빈출] 이등변삼각형 연쇄 외각 (5번)
• AB = AC = CD 조건 (각이 2배, 3배 누적):
  35° ➔ 외각 70° ➔ 이등변 70° ➔ ∠x = 35° + 70° = 105° 		모델 4. [빈출] 오각별 꼭짓점 각의 합 (6번)
• 외각 2회 적용 ➔ 한 삼각형 내부로 모임:
  ∠A + ∠B + ∠C + ∠D + ∠E = 180°
• ∠C = 70°일 때: ∠A + ∠B + ∠D + ∠E = 110°
구분 핵심 공식 및 성질 유도 원리 및 풀이 팁
한 꼭짓점 대각선 수 n - 3 (개) 자기 자신과 이웃 꼭짓점 2개 제외
대각선의 총 개수 n(n - 3)2 (개) 양 끝점에서 2회 중복 계산 차감
삼각형 외각의 성질 ∠외각 = 이웃하지 않는 두 내각의 합 평행선 엇각과 동위각 증명 (삼각형 전용)
부메랑 / 오각별 부메랑: a+b+c / 별: 총합 180° 외각 성질을 연쇄 적용하여 해결
[시험 직전 5초 리마인드]
① 다각형 대각선 총수는 n(n - 3)2, 악수 횟수는 n(n - 1)2이다.
② 삼각형 각도 계산 문제는 '외각 = 두 내각의 합'을 찾아 차례대로 누적 적용한다.
③ 사각형은 외각이 다른 세 각의 합과 절대 같지 않다 (오직 삼각형에서만 성립하는 성질).
