## 2. 다각형과 대각선의 성질 (6.1)

### (1) 기본 용어 정의
- **다각형(Polygon)**: 3개 이상의 선분으로 둘러싸인 평면도형 (변의 개수가 $n$개인 다각형 $\rightarrow$ **$n$각형**).
- **정다각형(Regular Polygon)**: 모든 <u>변의 길이가 같고</u>, 모든 <u>내각의 크기가 같은</u> 다각형.
  - `[함정]` 두 조건 중 하나만 만족하면 정다각형이 아님 (예: 마름모는 네 변이 같으나 정다각형 아님, 직사각형은 네 각이 같으나 정다각형 아님).
- **대각선(Diagonal)**: 다각형에서 <u>이웃하지 않는 두 꼭짓점을 이은 선분</u>.

### (2) 대각선 공식 유도 원리 및 핵심 도형
```
      A (꼭짓점)
     / \
    /   \
   B-----E   [도형 1: 다각형 대각선과 분할 삼각형 원리]
    \   /    • 꼭짓점 A에서 그을 수 있는 대각선: 자기 자신과 양옆 2개 제외 (n - 3)개
     \ /     • 대각선에 의해 나뉘는 삼각형의 개수: (n - 2)개
      C      • n각형 대각선의 총 개수: n(n - 3) / 2 개 (양 끝점 2회 중복 차감)
```

1. **한 꼭짓점에서 그을 수 있는 대각선의 개수**: **$n - 3$ (개)**
   - 원리: 자기 자신(1개)과 양옆의 이웃한 꼭짓점(2개)에는 대각선을 그을 수 없으므로 총 3개를 제외함.
2. **한 꼭짓점의 대각선에 의해 나뉘는 삼각형의 개수**: **$n - 2$ (개)**
   - 원리: 대각선을 1개 그을 때마다 삼각형이 1개씩 추가되므로, 대각선의 수($n-3$)보다 1개 더 많음.
3. `[빈출]` **$n$각형의 대각선의 총 개수**:
   $$\text{대각선의 총 개수} = \frac{n(n - 3)}{2}\text{ (개)}$$
   - 원리: $n$개의 꼭짓점에서 각각 $(n-3)$개씩 그을 수 있으나, 한 선분의 양 끝 꼭짓점에서 2번씩 중복 계산되므로 2로 나눔.

## 3. 삼각형 및 다각형의 내각과 외각 (6.2 ~ 6.4)

### (1) 내각과 외각의 기본 성질
- 다각형의 한 꼭짓점에서: **내각 $+$ 외각 $= 180^\circ$**
- `[빈출]` **삼각형의 외각의 성질**:
  - **"삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같다."**
  - **$\angle\text{ACD} = \angle\text{A} + \angle\text{B}$**
  - 원리: $\triangle\text{ABC}$에서 $\angle\text{A} + \angle\text{B} + \angle\text{ACB} = 180^\circ$이고 $\angle\text{ACD} + \angle\text{ACB} = 180^\circ$이므로 성립. (보조선 $CE \parallel AB$를 그으면 엇각 $\angle A$, 동위각 $\angle B$로 즉시 증명).

### (2) 다각형의 내각의 크기의 합
- **공식**: **내각의 크기의 합 $= 180^\circ \times (n - 2)$**
- **유도 원리**: 한 꼭짓점에서 대각선을 그으면 다각형이 $(n-2)$개의 삼각형으로 쪼개지며, 각 삼각형의 내각의 합은 $180^\circ$이므로 $180^\circ \times (n-2)$가 됨.
- **정$n$각형의 한 내각의 크기**:
  $$\text{한 내각의 크기} = \frac{180^\circ \times (n - 2)}{n}$$

### (3) 다각형의 외각의 크기의 합
- **공식**: **외각의 크기의 합 $= 360^\circ$ (변의 개수 $n$과 무관하게 항상 일정!)**
- **유도 원리**: $n$개의 꼭짓점에서 (내각 $+$ 외각)의 총합은 $180^\circ \times n$. 여기서 내각의 합 $180^\circ \times (n-2)$를 빼면 $180^\circ \times 2 = 360^\circ$가 남음.
- **정$n$각형의 한 외각의 크기**:
  $$\text{한 외각의 크기} = \frac{360^\circ}{n}$$

> 💡 **[초고속 풀이 비법] 정다각형의 한 내각을 3초 만에 구하는 법**  
> 복잡한 내각 공식 $\frac{180^\circ \times (n-2)}{n}$ 대신, **한 외각($\frac{360^\circ}{n}$)**을 먼저 계산한 뒤 **$180^\circ - (\text{한 외각})$**을 구하면 계산 실수 없이 암산으로 해결 가능!  
> • 예: 정팔각형($n=8$) ➔ 한 외각 $= 360^\circ \div 8 = 45^\circ$ ➔ 한 내각 $= 180^\circ - 45^\circ = 135^\circ$.

## 4. 원과 부채꼴의 기본 성질 (6.5)

### (1) 기본 용어 정리 및 기하 구조
- **원(Circle) $O$**: 평면 위의 한 점 $O$로부터 일정한 거리에 있는 모든 점으로 이루어진 도형.
- **호(Arc) $AB$ ($\stackrel{\frown}{AB}$)**: 원 위의 두 점 $A, B$를 양 끝으로 하는 원의 일부분.
- **현(Chord) $CD$**: 원 위의 두 점 $C, D$를 이은 선분 (원의 중심을 지나는 현 $=$ 지름 $=$ 가장 긴 현).
- **활꼴(Segment)**: 하나의 호와 하나의 현으로 이루어진 도형.
- **부채꼴(Sector) $AOB$**: 두 반지름 $OA, OB$와 호 $AB$로 이루어진 도형.
- **중심각**: 두 반지름이 이루는 각 $\angle AOB$ (호 $AB$에 대한 중심각).
- **할선(Secant)**: 원과 서로 다른 두 점에서 만나는 직선.

### (2) 부채꼴의 정비례 성질 vs 현의 비례하지 않음 비교 클리닉
1. `[빈출]` **부채꼴의 성질 (완벽한 정비례)**:
   - 한 원(또는 합동인 원)에서 중심각의 크기가 같으면 호의 길이와 부채꼴의 넓이는 각각 같다.
   - **호의 길이는 중심각의 크기에 정비례한다.**
   - **부채꼴의 넓이는 중심각의 크기에 정비례한다.**
2. `[함정]` **현의 성질 (정비례 성립하지 않음!)**:
   - 한 원(또는 합동인 원)에서 중심각의 크기가 같으면 **현의 길이는 같다**.
   - 길이가 같은 현에 대한 **중심각의 크기는 같다**.
   - **주의: 현의 길이는 중심각의 크기에 정비례하지 않는다!**
     - 중심각이 2배가 되어도 현의 길이는 2배가 되지 않고 2배보다 작다.
     - 기하학적 이유: $\triangle ABC$에서 삼각형의 변의 성질에 의해 $\text{현 } AC < \text{현 } AB + \text{현 } BC$.

## 5. 부채꼴의 호의 길이와 넓이 공식 (6.6)

반지름의 길이를 $r$, 중심각의 크기를 $x^\circ$, 호의 길이를 $l$, 넓이를 $S$, 원주율을 $\pi$(파이)라 할 때:

### (1) 원의 둘레의 길이($l$)와 넓이($S$)
- **둘레의 길이 (원주)**: $l = 2\pi r$
- **원의 넓이**: $S = \pi r^2$
- *참고: 중학교 수학부터는 원주율 3.14 대신 문자 $\pi$를 그대로 사용함.*

### (2) 부채꼴의 호의 길이($l$)와 넓이($S$)
- **호의 길이**:
  $$l = 2\pi r \times \frac{x}{360}$$
- **부채꼴의 넓이**:
  $$S = \pi r^2 \times \frac{x}{360} = \frac{1}{2}rl$$
- `[빈출]` **중심각($x$)을 모를 때**:
  반지름($r$)과 호의 길이($l$)만 주어지면 즉시 **$S = \frac{1}{2}rl$**을 적용하여 초고속 해결!
  - 유도 원리: 부채꼴을 무수히 잘게 쪼개어 번갈아 붙이면 밑변이 $\frac{1}{2}l$이고 높이가 $r$인 직사각형/평행사변형이 됨 ➔ $S = \frac{1}{2}rl$.

## 6. 6단원 필수 공식 및 시험 직전 체크포인트 올인원 총괄표

| 구분 | 핵심 공식 및 성질 | 출제 포인트 및 비고 |
| :--- | :--- | :--- |
| **한 꼭짓점 대각선** | $n - 3$ (개) | 자기 자신과 이웃 2개 제외 |
| **나뉘는 삼각형 개수** | $n - 2$ (개) | 내각 합 공식 유도의 기본 바탕 |
| **대각선의 총 개수** | $\frac{n(n - 3)}{2}$ (개) | 양 끝점 중복(2로 나눔) 주의 |
| **삼각형 외각 성질** | 한 외각 $=$ 이웃하지 않는 두 내각의 합 | $\angle\text{ACD} = \angle\text{A} + \angle\text{B}$ (단골 킬러 문항) |
| **$n$각형 내각의 합** | $180^\circ \times (n - 2)$ | 삼각형 개수($n-2$) $\times 180^\circ$ |
| **$n$각형 외각의 합** | **$360^\circ$** (항상 일정!) | 다각형 종류와 무관하게 무조건 $360^\circ$ |
| **정$n$각형 한 내각** | $\frac{180^\circ \times (n - 2)}{n} = 180^\circ - \frac{360^\circ}{n}$ | 외각($360^\circ \div n$)을 먼저 구하면 초고속! |
| **부채꼴 호의 길이** | $l = 2\pi r \times \frac{x}{360}$ | 중심각 크기에 정확히 정비례 |
| **부채꼴의 넓이** | $S = \pi r^2 \times \frac{x}{360} = \frac{1}{2}rl$ | 중심각 모를 땐 $\frac{1}{2}rl$ 즉시 적용! |
| **현의 정비례 여부** | **현의 길이는 중심각에 정비례하지 않는다!** | `[함정]` 합답형(O, X) 단골 오답 보기 |

### [시험 직전 5초 리마인드]
① 다각형 외각의 합은 변의 개수와 무관하게 무조건 **$360^\circ$**이다.  
② 삼각형에서 '새의 부리 모양'이나 '별 모양' 각도 문제는 **외각 성질($\angle\text{외각} = \text{두 내각의 합}$)**을 연쇄 적용하여 해결한다.  
③ 부채꼴 호의 길이와 넓이는 중심각에 정비례하지만, **현의 길이는 중심각에 정비례하지 않는다**.
