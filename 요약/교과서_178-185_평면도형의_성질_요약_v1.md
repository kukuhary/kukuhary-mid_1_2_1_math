## 1. [p.178~179] 6.0 단원 도입 및 초등 연계 기초 점검

### (1) 실생활과 예술 속 평면도형
- **알람브라 궁전의 타일 장식(테셀레이션)**: 기둥과 벽면을 가득 채운 다각형, 원 등의 기하학적 대칭성과 규칙성을 통해 평면도형의 성질에 대한 학습 동기를 유발함.

### (2) 초등 연계 필수 점검 3요소
1. **다각형의 뜻**: 선분으로만 둘러싸인 평면도형 (곡선이 포함된 원이나 입체도형은 제외).
2. **내각의 크기의 합 기초**:
   - 삼각형의 세 내각의 크기의 합 $= 180^\circ$
   - 사각형의 네 내각의 크기의 합 $= 360^\circ$
3. **원의 둘레와 넓이 기초**:
   - 원의 둘레(원주) $= \text{지름} \times \pi = 2\pi r$
   - 원의 넓이 $= \text{반지름} \times \text{반지름} \times \pi = \pi r^2$

## 2. [p.180~182] 6.1 다각형의 대각선의 개수

### (1) 기본 용어 정의
- **다각형(Polygon)**: 3개 이상의 선분으로 둘러싸인 평면도형 ($n$개의 선분 $\rightarrow$ **$n$각형**).
- **정다각형(Regular Polygon)**: 모든 <u>변의 길이가 같고</u>, 모든 <u>내각의 크기가 같은</u> 다각형.
  - `[함정]` 두 조건을 모두 충족해야 함 (마름모: 네 변만 같음 $\rightarrow$ 정다각형 X, 직사각형: 네 각만 같음 $\rightarrow$ 정다각형 X).
- **대각선(Diagonal)**: 다각형에서 <u>이웃하지 않는 두 꼭짓점을 이은 선분</u>.
  - `[주의]` 삼각형은 모든 꼭짓점이 서로 이웃하므로 대각선을 그을 수 없음 (대각선 수: 0개).

### (2) 대각선 핵심 공식 및 유도 원리
1. **한 꼭짓점에서 그을 수 있는 대각선의 개수**: **$n - 3$ (개)**
   - 원리: 자기 자신(1개)과 양옆의 이웃한 꼭짓점(2개)에는 대각선을 그을 수 없으므로 총 3개의 꼭짓점을 제외함.
2. **한 꼭짓점의 대각선에 의해 나뉘는 삼각형의 개수**: **$n - 2$ (개)**
   - 원리: 대각선을 1개 그을 때마다 삼각형이 1개씩 추가되므로 대각선 수($n-3$)보다 1개 더 많음.
3. `[빈출]` **$n$각형의 대각선의 총 개수**:
   $$\text{대각선의 총 개수} = \frac{n(n - 3)}{2}\text{ (개)}$$
   - 원리: $n$개의 꼭짓점에서 각각 $(n-3)$개씩 그을 수 있으나, 한 대각선의 양 끝점에서 2번씩 중복 계산되므로 2로 나눔.

### (3) 교과서 탐구 및 심화 유형 4대 정복 (p.181~182)
1. **대각선으로 다각형 분할하기 (`p.181 생각 넓히기`)**:
   - 한 꼭짓점에서 대각선 1개를 그어 사각형과 육각형으로 나누었을 때:
   - 두 다각형의 변의 수 합에서 공통 대각선 2개를 차감 $\rightarrow$ $4 + 6 - 2 = 8$ (**팔각형**).
   - 팔각형의 대각선 총 개수: $\dfrac{8 \times 5}{2} = 20$개.
2. **대각선 수로 다각형 이름 찾기 (`p.182 4번`)**:
   - $\dfrac{n(n-3)}{2} = 65 \implies n(n-3) = 130 = 13 \times 10 \implies n = 13$ (**십삼각형**).
3. **악수(네트워크) 횟수 구하기 (`p.182 5번 연결`)**:
   - 11명이 빠짐없이 서로 한 번씩 악수하는 총 횟수:
   - 꼭짓점 11개인 다각형의 (변의 개수 $+$ 대각선 개수) $\rightarrow \dfrac{11 \times 10}{2} = 55$번.
4. **두 꼭짓점에서 그은 대각선 합 (`p.182 6번 도전`)**:
   - 이웃하지 않는 두 꼭짓점에서 그은 대각선의 총합이 7개일 때:
   - 두 꼭짓점 사이의 공통 대각선 1개가 중복되므로 $(n-3) + (n-3) - 1 = 7 \implies 2n - 7 = 7 \implies n = 7$ (**칠각형**).
   - 칠각형의 대각선 총 개수: $\dfrac{7 \times 4}{2} = 14$개.

## 3. [p.183~185] 6.2 삼각형의 내각과 외각

### (1) 내각과 외각의 정의
- **내각**: 다각형에서 이웃한 두 변이 이루는 내부의 각.
- **외각**: 한 내각의 꼭짓점에서 한 변과 이웃한 다른 한 변의 연장선이 이루는 각.
- **기본 관계**: 다각형의 한 꼭짓점에서 **$(\text{내각}) + (\text{외각}) = 180^\circ$**.
  - `[참고]` 한 내각에 대한 외각은 2개이며, 맞꼭지각이므로 크기가 같음 (1개만 취급).

### (2) 삼각형의 내각과 외각의 관계 (핵심 정리)
$$\textbf{"삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같다."}$$
$$\angle\text{ACD} = \angle\text{A} + \angle\text{B}$$

- **증명 원리 (보조선 평행선 증명)**:
  - 꼭짓점 $C$를 지나고 변 $AB$에 평행한 반직선 $CE$를 그으면:
  - $\angle\text{ACE} = \angle\text{A}$ (엇각), $\angle\text{ECD} = \angle\text{B}$ (동위각).
  - 따라서 $\angle\text{ACD} = \angle\text{ACE} + \angle\text{ECD} = \angle\text{A} + \angle\text{B}$.

> `[함정 클리닉]` **사각형의 외각 오개념 정복 (`p.184 생각 넓히기`)**  
> • "사각형의 한 외각은 이웃하지 않는 세 내각의 합과 같을까?" $\rightarrow$ **아니다! (오답)**  
> • 사각형의 네 내각의 합은 $360^\circ$이므로 이웃하지 않는 세 내각의 합은 $360^\circ - (\text{내각})$이 됨.  
> • 외각은 $180^\circ - (\text{내각})$이므로 서로 같지 않음! **이 외각 공식은 오직 삼각형에서만 성립함**.

### (3) 시험 빈출 4대 기하 모델 완벽 정리 (p.185 해결해요)

1. **맞꼭지각/나비넥타이 모델 (`3번 (1)`)**:
   - 두 삼각형이 한 꼭짓점을 맞대고 있을 때, 맞꼭지각의 크기가 같으므로:
     $$\angle A + \angle B = \angle C + \angle D$$
2. **부메랑(오목 사각형) 모델 (`3번 (2)`, `4번`)**:
   - 안쪽으로 꺾인 각 $\angle x$는 세 뾰족한 내각의 합과 같음.
     $$\angle x = \angle a + \angle b + \angle c$$
   - *(유도)* 보조선을 그어 두 삼각형으로 분할 후 외각 성질 연속 적용.
3. `[빈출]` **이등변삼각형 연쇄 외각 모델 (`5번 추론`)**:
   - $\overline{AB} = \overline{AC} = \overline{CD}$ 형태:
     1) $\triangle ABC$ 이등변삼각형 $\rightarrow \angle ACB = \angle B = 35^\circ$
     2) $\triangle ABC$ 외각 $\angle CAD = 35^\circ + 35^\circ = 70^\circ$
     3) $\triangle ACD$ 이등변삼각형 $\rightarrow \angle D = \angle CAD = 70^\circ$
     4) $\triangle BCD$ 외각 $\angle x = \angle B + \angle D = 35^\circ + 70^\circ = 105^\circ$
4. `[빈출]` **별 모양(오각별) 꼭짓점 각의 합 모델 (`6번 도전`)**:
   - 오각별의 5개 꼭짓점의 각의 합은 항상 $180^\circ$임.
     $$\angle A + \angle B + \angle C + \angle D + \angle E = 180^\circ$$
   - $\angle C = 70^\circ$일 때: $\angle A + \angle B + \angle D + \angle E = 180^\circ - 70^\circ = 110^\circ$.

## 4. [요약표] 핵심 공식 및 기하 판별 비교표

| 영역 | 핵심 공식 / 정리 | 유도 원리 및 핵심 포인트 |
| :--- | :---: | :--- |
| **한 꼭짓점 대각선 수** | **$n - 3$** (개) | 자기 자신 및 양옆 이웃 2개 제외 |
| **나뉘는 삼각형 수** | **$n - 2$** (개) | 대각선 1개마다 삼각형 1개씩 추가 |
| **대각선의 총 개수** | **$\dfrac{n(n - 3)}{2}$** (개) | 양 끝점에서 2번 중복 계산 차감 |
| **한 꼭짓점 내·외각** | **내각 $+$ 외각 $= 180^\circ$** | 평각 ($180^\circ$) 관계 |
| **삼각형 외각 성질** | **한 외각 $=$ 다른 두 내각의 합** | 평행선 엇각과 동위각 증명 |
| **오목 사각형(부메랑)** | **안쪽 각 $=$ 세 뾰족한 각의 합** | 삼각형 외각 성질 2회 적용 |
| **오각별 각의 합** | **5개 꼭짓점 각의 합 $= 180^\circ$** | 외각 성질로 하나의 삼각형에 모음 |

## 5. [시험 직전 5초 리마인드]
1. $n$각형 대각선 총수는 $\dfrac{n(n-3)}{2}$이다.
2. 악수 횟수나 선분 총수는 $\dfrac{n(n-1)}{2}$이다.
3. 삼각형 각도 문제는 **외각 성질($\angle\text{외각} = \text{두 내각의 합}$)**을 찾아 연쇄 적용한다.
4. 부메랑 모양은 세 각을 더하면 안쪽 각이 되고, 별 모양의 다섯 꼭짓점 각의 합은 $180^\circ$이다.
