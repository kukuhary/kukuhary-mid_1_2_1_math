## 문항별 상세 해설

### 01. [경원중/도곡중 연계] 정답: ③ [하]
- **문제를 낸 이유**: 두 직선이 만날 때 형성되는 맞꼭지각의 크기가 서로 같다는 성질을 이용하여 일차방정식을 세우고 평각과의 관계를 정확히 계산하는 능력을 평가함.
- **정답 풀이**:
  1. 맞꼭지각의 크기는 서로 같으므로,  
     $3x - 15 = x + 45 \implies 2x = 60 \implies x = 30$
  2. $\angle AOC = 3(30^\circ) - 15^\circ = 75^\circ$
  3. 직선 $AB$는 평각($180^\circ$)이므로,  
     $\angle BOC = 180^\circ - \angle AOC = 180^\circ - 75^\circ = 105^\circ$
- **오답 피하기**:
  - ① $95^\circ$: $x=30$ 대입 후 뺄셈 계산 실수.
  - ② $100^\circ$: 이항 부호 착각으로 $2x=30$으로 오산.
  - ④ $110^\circ$: 맞꼭지각의 합을 $180^\circ$로 잘못 적용함.

### 02. [경원중/동아교과서 연계] 정답: ① [하]
- **문제를 낸 이유**: 한 꼭짓점에서 그을 수 있는 대각선의 수($n - 3$)로부터 다각형을 추론하고 대각선의 총 개수 공식($\frac{n(n-3)}{2}$)을 정확히 적용하는지 점검함.
- **정답 풀이**:
  1. $n$각형의 한 꼭짓점에서 그을 수 있는 대각선의 수는 $n - 3$이다.  
     $n - 3 = 6 \implies n = 9$ (구각형)
  2. 구각형의 대각선의 총 개수:  
     $\frac{9 \times (9 - 3)}{2} = \frac{9 \times 6}{2} = 27\text{개}$
- **오답 피하기**:
  - ② $35$개: 십각형의 대각선 개수($n=10$).
  - ③ $44$개: 십일각형의 대각선 개수($n=11$).
  - ④ $54$개: 십이각형의 대각선 개수($n=12$).

### 03. [한영중/해운대중 연계] 정답: ④ [중]
- **문제를 낸 이유**: 제2사분면 좌표의 부호 관계를 이해하고 미지수 부호 연산을 통해 새로운 점의 위치를 추론할 수 있는지 평가함.
- **정답 풀이**:
  1. 점 $P(a, b)$가 제2사분면 위의 점이므로 $a < 0, b > 0$이다.
  2. 점 $Q(-a, a - b)$의 각 좌표의 부호를 판정한다:
     - $x$좌표: $a < 0$이므로 $-a > 0$ (양수, $+$)
     - $y$좌표: $a < 0$이고 $b > 0$이므로 $a - b < 0$ (음수, $-$)
  3. $x$좌표가 양수이고 $y$좌표가 음수인 사분면은 **제4사분면**이다.
- **오답 피하기**:
  - ③ 제3사분면: $-a$를 음수로 착각한 대표 오답.
  - ② 제2사분면: 점 $P$의 사분면을 그대로 적용한 실수.

### 04. [한영중/경원중 연계] 정답: ② [중]
- **문제를 낸 이유**: 직선, 반직선, 선분의 엄밀한 수학적 정의와 반직선의 일치 조건(시작점과 방향의 동시 일치)을 구별할 수 있는지 평가함.
- **정답 풀이**:
  - ② $\overrightarrow{BC} = \overrightarrow{BD}$: 두 반직선 모두 시작점이 점 $B$로 같고, 점 $C$와 점 $D$가 모두 점 $B$의 오른쪽에 있어 방향이 같으므로 완전히 같은 반직선이다. (참)
  - ① $\overrightarrow{AB} = \overrightarrow{BA}$: 시작점이 서로 다르므로 다른 반직선이다. (거짓)
  - ③ $\overline{AB} = \overline{BC}$: 양 끝점이 다르며 길이가 같다는 조건이 없으므로 같지 않다. (거짓)
  - ④ $\overrightarrow{CB} = \overrightarrow{CD}$: 시작점은 $C$로 같으나 방향이 서로 반대이므로 다른 반직선이다. (거짓)
  - ⑤ $\overleftrightarrow{AB} \neq \overleftrightarrow{CD}$: 같은 직선 위의 점들이므로 양방향으로 한없이 뻗어나가는 동일한 직선이다. 즉 $\overleftrightarrow{AB} = \overleftrightarrow{CD}$이다. (거짓)

### 05. [한영중/경원중 연계] 정답: ⑤ [중]

### 06. [한영중/도곡중 연계] 정답: ② [중]
- **문제를 낸 이유**: 평행선 사이 꺾인 점에 평행선 보조선을 그어 엇각의 성질을 연쇄 활용할 수 있는지 평가함.
- **정답 풀이**:
  1. 꺾인 점 $B$를 지나고 두 직선에 평행한 보조선 $n$을 긋는다 ($l // n // m$).
  2. $l // n$이므로 엇각에 의해 보조선 위쪽 각은 $35^\circ$이다.
  3. 전체 $\angle B = 85^\circ$이므로 보조선 아래쪽 각은 $85^\circ - 35^\circ = 50^\circ$이다.
  4. $n // m$이므로 엇각에 의해 $\angle x = 50^\circ$이다.
- **오답 피하기**:
  - ④ $60^\circ$: $180^\circ - (35^\circ + 85^\circ) = 60^\circ$로 삼각형 내각 합을 엉뚱하게 적용한 오답.

### 07. [한영중/도곡중 연계] 정답: ① [중]
- **문제를 낸 이유**: 종이를 접었을 때 접은 각의 보존과 직사각형 평행선의 엇각이 결합하여 이등변삼각형이 만들어지는 원리를 이해하는지 평가함.
- **정답 풀이**:
  1. 평행선의 엇각: $\angle DEF = \angle GFE = 65^\circ$
  2. 접은 각의 성질: $\angle GEF = \angle DEF = 65^\circ$
  3. 따라서 삼각형 $GEF$는 두 밑각이 $65^\circ$로 같은 이등변삼각형이다.
  4. 세 내각의 합은 $180^\circ$이므로,  
     $\angle x = 180^\circ - (65^\circ + 65^\circ) = 50^\circ$
- **오답 피하기**:
  - ④ $65^\circ$: $\angle x$를 이등변삼각형 밑각과 같은 각으로 착각한 오답.

### 08. [도곡중/경원중 연계] 정답: ⑤ [중]

- **정답 풀이**:
  4개 중 3개를 고르는 4가지 경우를 검증한다:
  1. $(3, 5, 7)$: $7 < 3 + 5 = 8$ (가능, O)
  2. $(3, 5, 9)$: $9 \ge 3 + 5 = 8$ (불가능, X)
  3. $(3, 7, 9)$: $9 < 3 + 7 = 10$ (가능, O)
  4. $(5, 7, 9)$: $9 < 5 + 7 = 12$ (가능, O)  
  따라서 만들 수 있는 서로 다른 삼각형은 총 **3개**이다.

### 09. [도곡중/경원중 연계] 정답: ③ [중]
- **문제를 낸 이유**: 삼각형의 유일 작도 조건(SSS, SAS, ASA)을 이해하고 불능 및 부정 조건을 가려낼 수 있는지 평가함.
- **정답 풀이**:
  - ③ $a=6, b=8, \angle C=60^\circ$: 두 변과 그 '끼인각'이 주어졌으므로 SAS 조건에 의해 삼각형이 오직 하나로 정해진다. (참)
  - ① 세 각만 주어지면 크기가 다른 삼각형이 무수히 많이 결정된다. (거짓)
  - ② 가장 긴 변 $10 \ge 4 + 5 = 9$이므로 삼각형 자체가 만들어지지 않는다. (거짓)
  - ④ 두 변과 끼인각이 아닌 한 각이 주어졌으므로 모양이 하나로 정해지지 않는다. (거짓)
  - ⑤ 주어진 두 각의 합이 $80^\circ + 110^\circ = 190^\circ > 180^\circ$이므로 삼각형을 만들 수 없다. (거짓)

### 10. [한영중/도곡중 연계] 정답: ④ [중]
- **문제를 낸 이유**: 내각 이등분선과 평행선이 만드는 이등변삼각형 성질을 활용해 복잡한 둘레를 외곽 선분의 합으로 변환하는 능력을 평가함.
- **정답 풀이**:
  1. $DE // BC$이므로 엇각에 의해 $\angle DIB = \angle IBC$이고, 문제 조건에서 $\angle DBI = \angle IBC$이므로 $\triangle DBI$는 이등변삼각형이다 ($DI = DB$).
  2. 마찬가지로 $\triangle EIC$도 이등변삼각형이다 ($EI = EC$).
  3. $DE = DI + EI = DB + EC$
  4. $\triangle ADE$의 둘레 $= AD + AE + DE = AD + AE + DB + EC = (AD + DB) + (AE + EC) = AB + AC = 10 + 8 = 18\text{cm}$.

### 11. [도곡중/충남여중 연계] 정답: ① [중]
- **문제를 낸 이유**: 내각과 외각의 합($180^\circ$)과 외각 총합($360^\circ$)을 연계하여 정다각형을 특정하고 대각선 수를 계산할 수 있는지 평가함.
- **정답 풀이**:
  1. 한 외각의 크기를 $x^\circ$라 하면 한 내각의 크기는 $5x^\circ$이다.  
     $x + 5x = 180 \implies 6x = 180 \implies x = 30^\circ$
  2. 모든 정다각형의 외각의 총합은 $360^\circ$이므로,  
     변의 개수 $n = \frac{360^\circ}{30^\circ} = 12$ (정십이각형)
  3. 정십이각형의 대각선의 총 개수:  
     $\frac{12 \times (12 - 3)}{2} = \frac{12 \times 9}{2} = 54\text{개}$

### 12. [도곡중/해운대중 연계] 정답: ② [중]
- **문제를 낸 이유**: 중심각과 호의 길이 공식을 통해 반지름을 역산하고 부채꼴 넓이 공식($S=\frac{1}{2}rl$)과의 연결 능력을 측정함.
- **정답 풀이**:
  1. 호의 길이 공식: $l = 2\pi r \times \frac{150^\circ}{360^\circ} = \frac{5\pi r}{6}$  
     $\frac{5\pi r}{6} = 5\pi \implies r = 6\text{cm}$
  2. 부채꼴의 넓이 공식:  
     $S = \frac{1}{2} r l = \frac{1}{2} \times 6 \times 5\pi = 15\pi\text{cm}^2$

### 13. [한영중/경원중 심화] 정답: ④ [상]
- **문제를 낸 이유**: 공간 기하(3차원)에서 성립하는 평행·수직 성질과 직육면체 모델을 활용한 반례 검증 능력을 평가함.
- **정답 풀이**:
  - **ㄱ. (참)** 공간에서도 평행의 추이율은 성립한다. ($l // m, m // n \implies l // n$)
  - **ㄴ. (참)** 한 평면에 수직인 서로 다른 두 직선은 항상 평행하다.
  - **ㄷ. (거짓)** 한 평면에 평행한 두 직선은 한 점에서 만나거나 꼬인 위치일 수 있다. (반례: 직육면체 윗면에 평행한 두 모서리가 서로 직교하거나 꼬인 위치)
  - **ㄹ. (거짓)** 한 평면에 수직인 서로 다른 두 평면은 서로 수직으로 만날 수 있다. (반례: 직육면체 바닥면에 수직인 두 인접한 옆면)
  - **ㅁ. (참)** 한 직선에 수직인 서로 다른 두 평면은 서로 평행하다.  
  따라서 항상 옳은 것은 **ㄱ, ㄴ, ㅁ**이다.

### 14. [도곡중/경원중 심화] 정답: ⑤ [상]
- **문제를 낸 이유**: 정오각형 한 내각 유도, 대각선이 형성하는 이등변삼각형 밑각 계산, 삼각형 외각 정리를 융합한 고난도 각도 추론력을 평가함.
- **정답 풀이**:
  1. 정오각형의 한 내각의 크기:  
     $\frac{180^\circ \times (5 - 2)}{5} = \frac{540^\circ}{5} = 108^\circ$
  2. $\triangle ABC$는 $AB = BC$인 이등변삼각형이므로,  
     $\angle BCA = \frac{180^\circ - 108^\circ}{2} = 36^\circ$
  3. 마찬가지로 $\triangle BCD$도 $BC = CD$인 이등변삼각형이므로,  
     $\angle CBD = \frac{180^\circ - 108^\circ}{2} = 36^\circ$
  4. $\triangle PBC$에서 $\angle APB$는 꼭짓점 $P$의 외각이므로,  
     $\angle APB = \angle PBC + \angle PCB = 36^\circ + 36^\circ = 72^\circ$
- **오답 피하기**:
  - ① $60^\circ$: 정삼각형 각도로 막연히 추측한 오답.
  - ④ $70^\circ$: $36 + 36 = 72$를 십의 자리로 어림잡은 오답.

### 15. [도곡중/충남여중 심화] 정답: ③ [상]
- **문제를 낸 이유**: 정사각형 내부 4개 반원의 호가 겹쳐서 생기는 꽃잎 둘레의 기하학적 곡선 분해 능력을 측정함.
- **정답 풀이**:
  1. 색칠한 꽃잎 4개의 둘레는 정사각형의 네 변을 각각 지름으로 하는 **4개 반원의 호의 총합**과 정확히 일치한다.
  2. 각 반원의 지름은 $12\text{cm}$이므로,  
     반원 1개의 호의 길이 $= \frac{1}{2} \times (12\pi) = 6\pi\text{cm}$
  3. 이러한 반원의 호가 총 4개 모여 꽃잎 4개의 외곽 둘레 전체를 구성하므로,  
     둘레의 총합 $= 6\pi \times 4 = 24\pi\text{cm}$
- **오답 피하기**:
  - ① $12\pi\text{cm}$: 반원 2개 호만 더한 오답.
  - ② $18\pi\text{cm}$: 반원 3개 호의 합에 해당하는 오답.
