### 문항 1번 상세 해설 (작도의 기본 도구와 성질) — 정답: ②번 (ㄴ, ㄷ)
- **개념 분석**: 작도(Construction)는 오직 **눈금 없는 자**와 **컴퍼스**만을 사용하여 도형을 그리는 것을 뜻합니다.
- **보기 판정**:
  - ㄱ. [거짓] 눈금 없는 자에는 눈금이 없으므로 길이를 직접 잴 수 없습니다.
  - ㄴ. [참] 컴퍼스로 선분의 길이를 재어서 다른 직선 위로 옮깁니다.
  - ㄷ. [참] 두 점을 잇는 직선이나 선분의 연장선을 그을 때는 눈금 없는 자를 사용합니다.
  - ㄹ. [거짓] 각도기를 사용하는 것은 작도에 포함되지 않습니다. (각도기 사용 절대 금지)
- **[오답 탈출 Tip]**: '각도기', '눈금으로 재기'는 작도 시험의 1순위 오답 함정 선지입니다!

### 문항 2번 상세 해설 (직육면체의 위치 관계) — 정답: ③번 (8)
- **1단계: 모서리 AB와 꼬인 위치에 있는 모서리 개수 (x)**:
  - 만나는 모서리 (4개): AD, BC, AE, BF
  - 평행한 모서리 (3개): CD, EF, GH
  - 자기 자신 (1개): AB
  - 따라서 꼬인 위치는 $12 - (4 + 3 + 1) = \mathbf{4}$개 (DH, CG, EH, FG)입니다. ➔ $x = 4$
- **2단계: 면 ABCD와 평행한 모서리 개수 (y)**:
  - 윗면 ABCD와 만나지 않는 평행 밑면 EFGH의 4개 모서리: EF, FG, GH, HE ➔ $y = 4$개
- **3단계: 계산**: $x + y = 4 + 4 = 8$
- **[오답 탈출 Tip]**: 꼬인 위치 계산 시 평행한 모서리 3개를 누락 없이 제외해야 합니다.

### 문항 3번 상세 해설 (평행선 사이 꺾인 선의 각도) — 정답: ③번 (35)
- **1단계: 평행 보조선 긋기**: 두 꺾인 점 P, Q를 지나며 두 직선 l, m에 평행한 보조선을 각각 긋습니다.
- **2단계: 엇각을 이용한 계단식 각도 분할**:
  - 점 P 위쪽 각 = 직선 l과의 엇각 = 30°
  - 점 P 아래쪽 각 = $(3x - 15^\circ) - 30^\circ = 3x - 45^\circ$
  - 점 Q 위쪽 각 = 점 P 아래쪽 각과의 엇각 = $3x - 45^\circ$
  - 점 Q 아래쪽 각 = 직선 m과의 엇각 = $x^\circ$
- **3단계: 일차방정식 수립 및 풀이**:
  $$(3x - 45^\circ) + x^\circ = 95^\circ \implies 4x - 45 = 95 \implies 4x = 140 \implies \mathbf{x = 35}$$
- **[오답 탈출 Tip]**: $(3x - 15^\circ) - 30^\circ$의 부호 계산 실수에 주의하세요.

## [5쪽] 문항 4번 ~ 6번 상세 해설

### 문항 4번 상세 해설 (삼각형이 오직 하나로 정해질 조건) — 정답: ②번 (ㄴ, ㅁ)
- **보기별 정밀 판정**:
  - ㄱ. [거짓] $5 + 6 = 11 < 12$ 이므로 가장 긴 변이 나머지 두 변의 합보다 커서 삼각형 자체가 성립하지 않습니다.
  - ㄴ. [참] 두 변 AB, AC와 그 **끼인각 ∠A**가 주어졌으므로 오직 하나로 정해집니다 (SAS 조건).
  - ㄷ. [거짓 - 킬러 함정] 두 변 AB, BC의 끼인각은 공통 꼭짓점인 ∠B여야 합니다. 주어진 각이 ∠A이므로 점 C가 2개 생겨 오직 하나로 결정되지 않습니다!
  - ㄹ. [거짓] 세 각의 크기만 주어지면 크기가 다른 삼각형이 무수히 많이 만들어집니다.
  - ㅁ. [참] ∠C = 180° - (40° + 65°) = 75°이므로, 한 변 BC와 그 양 끝 각 ∠B, ∠C가 확정되어 오직 하나로 정해집니다 (ASA 조건).
- **[오답 탈출 Tip]**: 두 변이 주어졌을 때는 선분 알파벳의 공통 문자가 각의 이름과 일치하는지 반드시 확인하세요!

### 문항 5번 상세 해설 (직선과 선분의 개수 구하기) — 정답: ④번 (18)
- **1단계: 서로 다른 직선의 개수 (x)**:
  - 직선 l 위의 세 점 A, B, C로 만드는 직선: 직선 l 자체 ➔ **1**개
  - 직선 밖 두 점 P, Q를 잇는 직선: 직선 PQ ➔ **1**개
  - 점 P와 직선 l 위의 점 3개를 잇는 직선: PA, PB, PC ➔ **3**개
  - 점 Q와 직선 l 위의 점 3개를 잇는 직선: QA, QB, QC ➔ **3**개
  - 따라서 서로 다른 직선의 총 개수는 $x = 1 + 1 + 3 + 3 = \mathbf{8}$개입니다.
- **2단계: 서로 다른 선분의 개수 (y)**:
  - 선분은 양 끝점이 다르면 모두 다른 선분이므로, 5개의 점 중 2개를 택하는 모든 조합의 수:
    $$y = \frac{5 \times 4}{2} = \mathbf{10}\text{개}$$
- **3단계: 계산**: $x + y = 8 + 10 = \mathbf{18}$
- **[오답 탈출 Tip]**: 직선 l 자체(1개)와 두 외부점을 잇는 직선 PQ(1개)를 절대 누락하지 마세요!

### 문항 6번 상세 해설 (공간에서 위치 관계 참·거짓 명제) — 정답: ②번 (ㄱ, ㄴ)
- **직육면체 모형을 이용한 정밀 판정**:
  - ㄱ. [참] 한 평면에 수직인 서로 다른 두 직선은 평행합니다. (직육면체 바닥면에 서 있는 높이 모서리들)
  - ㄴ. [참] 평행선 추이성은 공간에서도 항상 성립합니다.
  - ㄷ. [거짓] 바닥면 P에 수직인 높이 모서리 l은 옆면 Q에 **포함**될 수 있으므로 항상 평행한 것은 아닙니다.
  - ㄹ. [거짓 - 대표 함정!] 높이 모서리 l에 수직인 가로 모서리 m과 세로 모서리 n은 서로 평행한 것이 아니라 직교($m \perp n$)합니다.
- **[오답 탈출 Tip]**: 공간 위치 관계 문제는 머리로 상상하지 말고 직육면체를 그려 모서리를 직접 대입하세요!

## [6쪽] 문항 7번 ~ 8번 상세 해설

### 문항 7번 상세 해설 (크기가 같은 각의 작도 원리) — 정답: ⑤번 (ㄱ, ㄴ, ㄷ, ㄹ)
- **1단계: 작도 순서 검증**:
  - 점 O 중심 호(㉠) ➔ 점 A 중심 호(㉣) ➔ 선분 CD 길이 재기(㉡) ➔ 점 P 중심 호(㉤) ➔ 반직선 AQ 긋기(㉢)
  - 따라서 가장 마지막에 수행하는 작도 과정은 ㉢이 맞습니다. (ㄱ 참)
- **2단계: 선분의 길이 관계 판정**:
  - 점 O와 점 A에서 같은 반지름으로 컴퍼스를 벌려 그렸으므로 $OC = OD = AP = AQ$가 성립합니다. (ㄴ 참)
  - 컴퍼스로 선분 CD의 길이를 재어 점 P에서 원호를 그려 교점 Q를 잡았으므로 $CD = PQ$입니다. (ㄷ 참)
- **3단계: 이용된 합동 원리**:
  - △OCD와 △APQ에서 세 대응변의 길이가 각각 같으므로 SSS 합동에 의해 ∠XOY = ∠PAQ가 성립합니다. (ㄹ 참)
- **[오답 탈출 Tip]**: $CD = PQ$ 및 SSS 합동 원리를 놓치지 말고 끝까지 꼼꼼히 확인하세요!

### 문항 8번 상세 해설 (정사각형 내부 직각삼각형 합동) — 정답: ⑤번 (ㄱ, ㄴ, ㄷ)
- **1단계: △ABE 와 △BCF 의 합동 증명 (ㄱ 참)**:
  - 정사각형이므로 $AB = BC = 12\text{ cm}$, $\angle B = \angle C = 90^\circ$이고, 조건에서 $BE = CF = 5\text{ cm}$입니다.
  - 두 변의 길이와 그 끼인각이 각각 같으므로 △ABE ≡ △BCF (SAS 합동)입니다.
- **2단계: 대응변의 길이 (ㄴ 참)**:
  - 합동인 두 삼각형의 대응변의 길이는 서로 같으므로 선분 AE와 선분 BF의 길이는 같습니다 ($AE = BF$).
- **3단계: 두 선분의 수직 교차 증명 (ㄷ 참)**:
  - 직각삼각형 ABE에서 $\angle BAE = \bullet$, $\angle AEB = \times$라 하면 $\bullet + \times = 90^\circ$입니다.
  - 합동에 의해 $\angle CBF = \angle BAE = \bullet$이므로, 교점 P를 포함하는 △PBE에서:
    $$\angle BPE = 180^\circ - (\angle PBE + \angle PEB) = 180^\circ - (\bullet + \times) = 180^\circ - 90^\circ = 90^\circ \implies AE \perp BF$$
- **[오답 탈출 Tip]**: 합동을 증명했다면 대응변의 길이($AE = BF$)는 당연히 참으로 체크해야 합니다!
