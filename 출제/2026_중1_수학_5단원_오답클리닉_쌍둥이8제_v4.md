### [문항 2번 해설] (직육면체 모서리의 위치 관계)
- **정답**: **③번 (8)**
- **1단계: 모서리 AB와 꼬인 위치에 있는 모서리 개수 (x)**:

### [문항 3번 해설] (평행선 사이 꺾인 선의 각도 계산)
- **정답**: **③번 (35)**
- **1단계: 평행 보조선 긋기**: 두 꺾인 점 $P, Q$를 지나며 두 직선 $l, m$에 평행한 보조선을 각각 긋습니다.
- **2단계: 엇각을 이용한 계단식 각도 분할**:
  - 점 $P$ 위쪽 각 = 직선 $l$과의 엇각 = $30^\circ$
  - 점 $P$ 아래쪽 각 = $(3x - 15^\circ) - 30^\circ = 3x - 45^\circ$
  - 점 $Q$ 위쪽 각 = 점 $P$ 아래쪽 각과의 엇각 = $3x - 45^\circ$
  - 점 $Q$ 아래쪽 각 = 직선 $m$과의 엇각 = $x^\circ$
- **3단계: 일차방정식 수립 및 풀이**:
  - $(3x - 45^\circ) + x^\circ = 95^\circ \implies 4x - 45 = 95 \implies 4x = 140 \implies x = 35$.
- **[오답 탈출 Tip]**: $(3x - 15^\circ) - 30^\circ$ 계산 시 부호 실수에 유의하세요.

### [문항 7번 해설] (크기가 같은 각의 작도와 삼각형의 합동)
- **정답**: **⑤번 (ㄱ, ㄴ, ㄷ, ㄹ)**
- **작도 순서**: ㉠ $\to$ ㉣ $\to$ ㉡ $\to$ ㉤ $\to$ ㉢
- **보기 판정**:
  - ㄱ: [참] 가장 마지막 단계는 두 점 $A, Q$를 연결하는 반직선 $AQ$를 긋는 ㉢입니다.
  - ㄴ: [참] 동일한 컴퍼스 반지름으로 원호를 그렸으므로 $OC = OD = AP = AQ$입니다.
  - ㄷ: [참] 점 $P$에서 $CD$의 길이를 재어 그렸으므로 $CD = PQ$입니다.
  - ㄹ: [참] 세 쌍의 대응변 길이가 같으므로 $\triangle OCD \equiv \triangle APQ$ (SSS 합동)이며, 이에 따라 대응각인 $\angle XOY = \angle PAQ$임이 증명됩니다.

### [문항 8번 해설] (정사각형 내부 삼각형 합동과 직교 증명)
- **정답**: **⑤번 (ㄱ, ㄴ, ㄷ)**
- **1단계: 삼각형 합동 증명 (ㄱ)**:
  - $\triangle ABE$와 $\triangle BCF$에서:
    - $AB = BC = 12\text{ cm}$ (정사각형의 한 변)
    - $BE = CF = 5\text{ cm}$ (조건)
    - $\angle B = \angle C = 90^\circ$ (정사각형의 한 내각)
  - 두 변과 끼인각이 같으므로 $\triangle ABE \equiv \triangle BCF$ (SAS 합동) [참]
- **2단계: 대응변의 길이 (ㄴ)**:
  - 합동인 두 삼각형의 대응변이므로 $AE = BF$ [참]
- **3단계: 두 선분의 수직 교차 증명 (ㄷ)**:
  - $\angle BAE = \bullet$, $\angle AEB = \times$라 하면, 직각삼각형 $\triangle ABE$에서 $\bullet + \times = 90^\circ$.
  - 합동에 의해 $\angle CBF = \angle BAE = \bullet$.
  - $\triangle PBE$에서 $\angle PBE + \angle PEB = \bullet + \times = 90^\circ$.
  - 따라서 $\angle BPE = 180^\circ - 90^\circ = 90^\circ$이므로 $AE \perp BF$ [참]
