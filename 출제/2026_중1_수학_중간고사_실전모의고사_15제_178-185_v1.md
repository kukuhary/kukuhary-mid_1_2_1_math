## 15개 전 문항 심층 해설

### 01번 해설
- **난이도**: [하]
- **정답**: **③**
- **[정답 풀이]**:
  1. $n$각형의 한 꼭짓점에서 그을 수 있는 대각선의 개수는 $(n - 3)$개이다.
  2. 문제에서 한 꼭짓점에서 그을 수 있는 대각선의 개수가 $9$개이므로:
     $$n - 3 = 9 \implies n = 12 \quad (\text{십이각형})$$
  3. $n$각형의 대각선의 총 개수 공식은 $\dfrac{n(n - 3)}{2}$이므로:
     $$\text{대각선의 총 개수} = \frac{12 \times (12 - 3)}{2} = \frac{12 \times 9}{2} = 54\text{ (개)}$$
  따라서 정답은 ③이다.
- **[오답 피하기]**:
  - ① $44$개: $n = 11$인 십일각형의 대각선 총 개수($\frac{11 \times 8}{2} = 44$)로 계산한 오류.
  - ② $48$개: 공식을 $\frac{n(n-4)}{2}$ 등으로 잘못 암기하여 발생한 계산 오류.
  - ④ $65$개: $n = 13$인 십삼각형의 대각선 총 개수($\frac{13 \times 10}{2} = 65$)로 계산한 오류.
  - ⑤ $77$개: $n = 14$인 십사각형의 대각선 총 개수($\frac{14 \times 11}{2} = 77$)로 계산한 오류.
- **[문제를 낸 이유]**:
  - 2022 개정 수학 교육과정 성취기준: 다각형의 대각선의 개수를 구하는 과정을 이해한다.
  - 동아출판 중1 수학 교과서 p.180~181의 핵심 공식을 기본적으로 적용할 수 있는지 점검하기 위해 출제함.

### 02번 해설
- **난이도**: [하]
- **정답**: **④**
- **[정답 풀이]**:
  1. 삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같다.
  2. 따라서 외각 $\angle ACD$는 이웃하지 않는 두 내각 $\angle A$와 $\angle B$의 합과 같다:
     $$\angle ACD = \angle A + \angle B = 55^\circ + 65^\circ = 120^\circ$$
  따라서 $x = 120$이며, 정답은 ④이다.
- **[오답 피하기]**:
  - ① $105^\circ$: $55^\circ + 50^\circ$ 등으로 덧셈을 실수한 오류.
  - ② $110^\circ$: $180^\circ - (55^\circ + 65^\circ) = 60^\circ$를 구한 뒤 내각 $\angle C$와 관련된 연산 혼동.
  - ③ $115^\circ$: $180^\circ - 65^\circ$로 $\angle B$의 외각을 구한 오류.
  - ⑤ $125^\circ$: $180^\circ - 55^\circ$로 $\angle A$의 외각을 구한 오류.
- **[문제를 낸 이유]**:
  - 2022 개정 수학 교육과정 성취기준: 삼각형의 내각과 외각 사이의 관계를 이해한다.
  - 교과서 p.183~184에서 배운 '삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같다'는 기본 원리를 정확히 적용하는 능력을 평가함.

### 03번 해설
- **난이도**: [중]
- **정답**: **⑤**
- **[정답 풀이]**:
  - **ㄱ (거짓)**: 정다각형은 모든 '변의 길이'가 같고, 모든 '내각의 크기'가 같은 다각형이다. 마름모는 네 변의 길이가 모두 같지만 네 내각의 크기가 다를 수 있으므로 정다각형이 아니다. 따라서 거짓이다.
  - **ㄴ (참)**: $n$각형의 한 꼭짓점에서 그을 수 있는 대각선의 개수는 $n - 3$개이다. $n - 3 = 7 \implies n = 10$이므로 십각형이 맞다. (참)
  - **ㄷ (참)**: $n$각형의 변의 개수 $n$과 대각선의 총 개수 $\dfrac{n(n-3)}{2}$이 같으려면:
    $$n = \frac{n(n - 3)}{2} \implies 2n = n^2 - 3n \implies n^2 - 5n = 0 \implies n(n - 5) = 0$$
    다각형에서 $n \ge 3$이므로 $n = 5$, 즉 오각형뿐이다. (참)
  - **ㄹ (참)**: 대각선은 '이웃하지 않는 두 꼭짓점을 이은 선분'인데, 삼각형은 3개의 꼭짓점이 모두 서로 이웃하므로 대각선을 그을 수 없다 (대각선 개수 $0$개). (참)
  따라서 옳은 것은 ㄴ, ㄷ, ㄹ이며 정답은 ⑤이다.
- **[오답 피하기]**:
  - ① ㄱ, ㄴ: 마름모의 반례를 간과하여 ㄱ을 참으로 오판한 오류.
  - ② ㄴ, ㄷ: 삼각형에 대각선이 존재하지 않는다는 기본 정의(ㄹ)를 누락한 오류.

### 07번 해설

### 11번 해설
- **난이도**: [상]
- **정답**: **③**
- **[정답 풀이]**:
  1. 삼각형 $ABC$에서 외각의 성질에 의해:
     $$\angle ACE = \angle A + \angle B$$
  2. 선분 $CD$가 $\angle ACE$의 이등분선이므로:
     $$\angle DCE = \frac{1}{2}\angle ACE = \frac{1}{2}(\angle A + \angle B)$$
  3. 한편 삼각형 $DBC$에서 꼭짓점 $C$에서의 외각 $\angle DCE$는 이웃하지 않는 두 내각의 합과 같으므로:
     $$\angle DCE = \angle D + \angle DBC = \angle D + \frac{1}{2}\angle B$$
  4. 위 두 식의 좌변이 같으므로 우변끼리 비교하면:
     $$\frac{1}{2}\angle A + \frac{1}{2}\angle B = \angle D + \frac{1}{2}\angle B \implies \angle D = \frac{1}{2}\angle A$$
  5. 따라서 $\angle A = 2 \times \angle D = 2 \times 34^\circ = 68^\circ$이다.
  6. 삼각형 $ABC$에서 세 내각의 크기의 합은 $180^\circ$이므로:
     $$\angle B = 180^\circ - (\angle A + \angle ACB) = 180^\circ - (68^\circ + 56^\circ) = 180^\circ - 124^\circ = 56^\circ$$
  따라서 정답은 ③이다.
- **[오답 피하기]**:
  - ① $48^\circ$: $\angle A = 34^\circ$로 $\angle D$와 같다고 착각하여 $180^\circ - (34^\circ + 56^\circ) = 90^\circ$에서 실수한 오류.
  - ② $52^\circ$: $\angle A = 68^\circ$ 계산 후 뺄셈 실수 ($180 - 128 = 52$).
  - ④ $60^\circ$: 임의의 각도로 추정한 오류.
  - ⑤ $64^\circ$: $124^\circ$의 보각을 $64^\circ$로 잘못 뺀 뺄셈 오류.

### 13번 해설
- **난이도**: [상]
- **정답**: **⑤**
- **[정답 풀이]**:
  1. 삼각형 $ABC$에서 세 내각의 합은 $180^\circ$이므로:
     $$\angle B + \angle C = 180^\circ - \angle A = 180^\circ - 72^\circ = 108^\circ$$
  2. 선분 $BI$와 $CI$가 각각 $\angle B$와 $\angle C$의 이등분선이므로:
     $$\angle IBC + \angle ICB = \frac{1}{2}\angle B + \frac{1}{2}\angle C = \frac{1}{2}(\angle B + \angle C) = \frac{1}{2} \times 108^\circ = 54^\circ$$
  3. 삼각형 $IBC$에서 세 내각의 합은 $180^\circ$이므로:
     $$\angle BIC = 180^\circ - (\angle IBC + \angle ICB) = 180^\circ - 54^\circ = 126^\circ$$
  - *(공식 활용)*: $\angle BIC = 90^\circ + \dfrac{1}{2}\angle A = 90^\circ + 36^\circ = 126^\circ$.
  따라서 정답은 ⑤이다.
- **[오답 피하기]**:
  - ① $116^\circ$: $90^\circ + 26^\circ$로 $\angle A$의 절반을 잘못 나눈 오류.
  - ② $118^\circ$: 단순 뺄셈 실수.
  - ③ $120^\circ$: $180^\circ - 60^\circ$로 어림짐작한 오류.
  - ④ $124^\circ$: $180^\circ - 56^\circ = 124^\circ$로 $\frac{1}{2}(\angle B+\angle C)$를 잘못 계산한 오류.
- **[문제를 낸 이유]**:
  - 교과서 p.183~184의 내각의 성질을 확장하여, 두 내각의 이등분선이 이루는 각의 크기를 단계별로 도출하는 심화 기하 해석 능력을 평가함.

### 14번 해설
- **난이도**: [상]
- **정답**: **④**
- **[정답 풀이]**:
  1. 꼭짓점 $C$에서의 외각의 크기가 $75^\circ$이므로, 내각과 외각의 합은 $180^\circ$에서:
     $$\angle C = 180^\circ - 75^\circ = 105^\circ$$
  2. 교과서 p.184 `[생각 넓히기]`에서 확인했듯이, **사각형의 외각은 이웃하지 않는 세 각의 합과 같지 않으므로**, 반드시 사각형 내각의 총합($360^\circ$)을 이용해야 한다.
  3. 사각형 $ABCD$의 네 내각의 크기의 합은 $360^\circ$이므로:
     $$\angle A + \angle B + \angle C + \angle D = 360^\circ$$
     $$85^\circ + 2x^\circ + 105^\circ + (3x - 10)^\circ = 360^\circ$$
  4. 식을 정리하면:
     $$5x^\circ + (85 + 105 - 10)^\circ = 360^\circ \implies 5x^\circ + 180^\circ = 360^\circ \implies 5x^\circ = 180^\circ \implies x = 36$$
  5. 구하고자 하는 각은 $\angle B$의 크기이므로:
     $$\angle B = 2x^\circ = 2 \times 36^\circ = 72^\circ$$
  따라서 정답은 ④이다.
- **[오답 피하기]**:
  - ① $64^\circ$: $5x = 160 \implies x = 32 \implies 2x = 64$로 이항 실수.
  - ② $68^\circ$: 단순 연산 오류.
  - ③ $70^\circ$: $x = 35$로 잘못 구한 오류.
  - ⑤ $76^\circ$: $x = 38$로 잘못 구한 오류.
- **[문제를 낸 이유]**:
  - 교과서 p.184 `[생각 넓히기]`에서 집중 조명한 '사각형 외각 오개념'을 정면으로 타깃팅하여, 삼각형의 외각 공식과 사각형 내각의 합($360^\circ$)을 명확히 구분할 수 있는지 검증하기 위해 출제함.

### 15번 해설
- **난이도**: [상]
- **정답**: **②**
- **[정답 풀이]**:
  1. 꼭짓점 $A$와 점 $P$를 지나는 반직선 $AP$를 긋고, 선분 $BC$와 만나는 점을 $D$라 하자.
  2. 삼각형 $ABP$에서 변 $AP$의 연장선 방향의 외각 $\angle BPD$는 이웃하지 않는 두 내각의 합과 같다:
     $$\angle BPD = \angle BAP + \angle ABP$$
  3. 삼각형 $ACP$에서 변 $AP$의 연장선 방향의 외각 $\angle CPD$는 이웃하지 않는 두 내각의 합과 같다:
     $$\angle CPD = \angle CAP + \angle ACP$$
  4. 따라서 구하는 각 $\angle BPC$는 두 각의 합이다:
     $$\angle BPC = \angle BPD + \angle CPD = (\angle BAP + \angle CAP) + \angle ABP + \angle ACP = \angle A + \angle ABP + \angle ACP$$
  5. 주어진 값을 대입하면:
     $$x = 54^\circ + 28^\circ + 32^\circ = 114^\circ$$
  따라서 정답은 ②이다.
- **[오답 피하기]**:
  - ① $110^\circ$: $54^\circ + 28^\circ + 28^\circ = 110^\circ$로 $\angle ACP$를 잘못 본 오류.
  - ③ $118^\circ$: $54^\circ + 60^\circ = 114^\circ$ 대신 $118^\circ$로 덧셈 실수한 오류.
  - ④ $122^\circ$: $180^\circ - (28^\circ + 32^\circ) = 120^\circ$ 등 다른 방식의 오개념 혼합 오류.
  - ⑤ $126^\circ$: $180^\circ - 54^\circ = 126^\circ$로 단순 뺀 오류.
- **[문제를 낸 이유]**:
  - 교과서 p.185 문제 4(부메랑 모형)의 기하학적 본질이 내부 점 분할 보조선($AP$)에 의한 삼각형 외각의 합임을 완벽히 증명하고 적용할 수 있는지 확인하기 위해 출제함.
