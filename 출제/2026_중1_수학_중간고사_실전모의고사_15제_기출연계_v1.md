## 01번 해설
- **정답**: **③**
- **난이도**: [하]
- **원천 기출 연계**: [2025 경원중 01번], [2025 도곡중 04번]
- **문제를 낸 이유**: 두 직선이 교차할 때 형성되는 맞꼭지각의 크기가 서로 같다는 기본 기하 원리를 바탕으로 일차방정식을 세우고, 이웃하는 각과의 평각($180^\circ$) 관계를 정확히 계산할 수 있는지 평가한다.
- **[정답 풀이]**:
  1. 두 직선 $AB$와 $CD$가 점 $O$에서 만나므로 $\angle AOC$와 $\angle BOD$는 맞꼭지각이다.
  2. 맞꼭지각의 크기는 서로 같으므로,
     $$3x - 15 = x + 45$$
  3. 좌변으로 $x$항을 이항하고 우변으로 상수항을 이항하여 정리하면,
     $$3x - x = 45 + 15 \implies 2x = 60 \implies x = 30$$
  4. 따라서 $\angle AOC$의 크기는,
     $$\angle AOC = 3 \times 30^\circ - 15^\circ = 90^\circ - 15^\circ = 75^\circ$$
  5. 직선 $AB$는 평각($180^\circ$)이므로 구하고자 하는 $\angle BOC$의 크기는,
     $$\angle BOC = 180^\circ - \angle AOC = 180^\circ - 75^\circ = 105^\circ$$
- **[오답 피하기]**:
  - ① $95^\circ$: $x = 30$을 구한 후 $180^\circ - (75^\circ + 10^\circ)$ 등으로 계산 실수를 범한 오답이다.
  - ② $100^\circ$: $3x - 15 = x + 45$에서 이항 시 부호를 혼동하여 $2x = 30 \implies x = 15$로 잘못 푼 경우이다.
  - ④ $110^\circ$: 맞꼭지각의 합을 $180^\circ$로 착각하여 식을 잘못 세운 경우이다.
  - ⑤ $115^\circ$: $x$값 계산 후 마지막 뺄셈에서 $180^\circ - 65^\circ$로 잘못 뺀 경우이다.

## 02번 해설
- **정답**: **①**
- **난이도**: [하]
- **원천 기출 연계**: [2025 경원중 12번], [동아 교과서 p.180]
- **문제를 낸 이유**: 다각형의 한 꼭짓점에서 그을 수 있는 대각선의 개수 공식($n - 3$)을 통해 다각형의 변의 개수를 파악하고, 대각선의 총 개수 공식($\frac{n(n-3)}{2}$)을 정확하게 적용할 수 있는지 점검한다.
- **[정답 풀이]**:
  1. 다각형의 꼭짓점의 개수를 $n$이라 하면, 한 꼭짓점에서 그을 수 있는 대각선의 개수는 자기 자신과 이웃한 두 꼭짓점을 제외하므로 $n - 3$개이다.
  2. 문제에서 한 꼭짓점에서 그을 수 있는 대각선의 개수가 $6$개라 하였으므로,
     $$n - 3 = 6 \implies n = 9 \text{ (구각형)}$$
  3. $n$각형의 대각선의 총 개수 공식은 $\frac{n(n - 3)}{2}$이므로, 구각형의 대각선의 총 개수는,
     $$\frac{9 \times (9 - 3)}{2} = \frac{9 \times 6}{2} = 27\text{개}$$
- **[오답 피하기]**:
  - ② $35$개: $n - 3 = 7 \implies n = 10$으로 잘못 계산하여 십각형의 대각선 수 $\frac{10 \times 7}{2} = 35$를 고른 오답이다.
  - ③ $44$개: 십일각형의 대각선의 개수($\frac{11 \times 8}{2} = 44$)이다.
  - ④ $54$개: 십이각형의 대각선의 개수($\frac{12 \times 9}{2} = 54$)이다.
  - ⑤ $65$개: 십삼각형의 대각선의 개수이다.

  1. 점 $P(a, b)$가 제2사분면 위의 점이므로, $x$좌표는 음수이고 $y$좌표는 양수이다.
     $$a < 0, \quad b > 0$$
  2. 점 $Q(-a, a - b)$의 각 좌표의 부호를 판별한다:
     - $x$좌표: $-a$
       $a < 0$이므로 양변에 $-1$을 곱하면 $-a > 0$ (양수, $+$)
     - $y$좌표: $a - b$
       $a < 0$ (음수)이고 $b > 0$ (양수)이므로, 음수에서 양수를 뺀 값은 항상 음수이다.
       $$a - b < 0 \text{ (음수, }-)$$
  3. 점 $Q$는 $x$좌표가 양수($+$)이고 $y$좌표가 음수($-$)이므로, 좌표평면의 **제4사분면** 위의 점이다.
- **[오답 피하기]**:
  - ① 제1사분면: $x > 0, y > 0$이어야 하므로 오답이다.
  - ② 제2사분면: 점 $P$의 사분면을 그대로 적용하거나 $-a$의 부호를 착각한 오답이다.
  - ③ 제3사분면: $a - b < 0$만 보고 $-a$도 음수일 것으로 혼동한 가장 대표적인 함정 오답이다.
  - ⑤ 어느 사분면에도 속하지 않는다: 축 위의 점($x=0$ 또는 $y=0$)일 때 해당하므로 오답이다.

## 10번 해설
- **정답**: **④**

- **문제를 낸 이유**: 내각의 이등분선과 평행선이 만날 때 형성되는 두 밑각의 일치로 인해 이등변삼각형이 만들어지는 원리를 활용하여, 복잡한 둘레의 길이를 간단한 외곽 선분의 길이의 합으로 전환하는 기하학적 사고력을 평가한다.

  1. 선분 $DE$와 선분 $BC$가 평행하다($DE // BC$).
  2. $DE // BC$이므로 엇각의 성질에 의해,
     $$\angle DIB = \angle IBC$$
  3. 선분 $BI$는 $\angle B$의 이등분선이므로 $\angle DBI = \angle IBC$이다.
  4. 따라서 $\angle DBI = \angle DIB$이므로, 삼각형 $DBI$는 두 밑각의 크기가 같은 이등변삼각형이다!
     $$\overline{DI} = \overline{DB}$$

     $$\overline{EI} = \overline{EC}$$

     $$\overline{DE} = \overline{DI} + \overline{EI} = \overline{DB} + \overline{EC}$$

     $$\text{둘레} = \overline{AD} + \overline{AE} + \overline{DE} = \overline{AD} + \overline{AE} + (\overline{DB} + \overline{EC}) = (\overline{AD} + \overline{DB}) + (\overline{AE} + \overline{EC}) = \overline{AB} + \overline{AC}$$
  8. 주어진 길이를 대입하면,
     $$\text{둘레} = 10\text{cm} + 8\text{cm} = 18\text{cm}$$

## 12번 해설
- **정답**: **②**
- **난이도**: [중]
- **원천 기출 연계**: [2025 도곡중 15번], [2025 해운대중 18번]
- **문제를 낸 이유**: 부채꼴의 중심각과 호의 길이 공식($l = 2\pi r \times \frac{x}{360}$)을 통해 반지름을 정확하게 역산하고, 부채꼴의 넓이 공식($S = \frac{1}{2}rl$)과의 유기적 연결 능력을 측정한다.
- **[정답 풀이]**:
  1. 부채꼴의 반지름의 길이를 $r\text{cm}$라 하자.
  2. 호의 길이 공식:
     $$l = 2\pi r \times \frac{x}{360} = 2\pi r \times \frac{150}{360} = 2\pi r \times \frac{5}{12} = \frac{5\pi r}{6}$$
  3. 호의 길이가 $5\pi\text{cm}$라 하였으므로,
     $$\frac{5\pi r}{6} = 5\pi \implies \frac{r}{6} = 1 \implies r = 6\text{cm}$$
  4. 부채꼴의 넓이 $S$는 공식 $S = \frac{1}{2}rl$에 의해,
     $$S = \frac{1}{2} \times 6 \times 5\pi = 15\pi\text{cm}^2$$
- **[오답 피하기]**:
  - ① $12\pi\text{cm}^2$: 반지름 $r$을 잘못 계산하여 구한 오답이다.
  - ③ $18\pi\text{cm}^2$: 원 전체의 넓이($36\pi$)의 절반으로 착각한 오답이다.
  - ⑤ $24\pi\text{cm}^2$: 공식 적용 시 $\frac{1}{2}$을 빠뜨리고 계산한 경우이다.

## 13번 해설
- **정답**: **④**
- **난이도**: [상]
- **원천 기출 연계**: [2025 한영중 18번], [2025 경원중 07번]
- **문제를 낸 이유**: 평면 기하의 상식이 공간 기하(3차원)에서 성립하지 않는 반례들을 정확하게 인지하고, 직육면체 공간 모델을 활용하여 직선과 평면의 수직·평행 관계를 엄밀하게 판별할 수 있는지 평가한다.
- **[정답 풀이]**:
  - **ㄱ. $l // m$ 이고 $m // n$ 이면 $l // n$ 이다. (참)**
    평행한 두 직선 사이의 평행 관계는 공간에서도 추이율이 완벽하게 성립한다.
  - **ㄴ. $l \perp P$ 이고 $m \perp P$ 이면 $l // m$ 이다. (참)**
    하나의 평면 $P$에 수직인 서로 다른 두 직선 $l, m$은 공간에서 항상 서로 평행하다.
  - **ㄷ. $l // P$ 이고 $m // P$ 이면 $l // m$ 이다. (거짓)**
    [반례] 직육면체의 밑면 $P$에 대하여, 윗면의 가로 모서리 $l$과 세로 모서리 $m$은 모두 밑면 $P$와 평행하지만, $l$과 $m$은 한 점에서 수직으로 만난다. 또한 꼬인 위치에 있을 수도 있다.
  - **ㄹ. $P \perp Q$ 이고 $Q \perp R$ 이면 $P // R$ 이다. (거짓)**
    [반례] 직육면체에서 바닥면을 $Q$라 하면, 서로 직교하는 두 옆면 $P, R$은 각각 바닥면 $Q$와 수직이지만, $P$와 $R$은 평행하지 않고 한 직선(기둥 모서리)에서 수직으로 만난다.
  - **ㅁ. $P \perp l$ 이고 $Q \perp l$ 이면 $P // Q$ 이다. (참)**
    하나의 직선 $l$에 수직인 서로 다른 두 평면 $P, Q$는 항상 서로 평행하다.
  - 따라서 항상 옳은 것은 **ㄱ, ㄴ, ㅁ**이다.
- **[오답 피하기]**:
  - 평면에서의 상식(수직인 두 직선은 평행 등)을 3차원 공간 평면에 그대로 투영하면 ㄷ, ㄹ을 참으로 잘못 판단하기 쉬우므로, 반드시 직육면체 모델을 머릿속에 떠올려 검증해야 한다.

## 14번 해설
- **정답**: **⑤**
- **난이도**: [상]
- **원천 기출 연계**: [2025 도곡중 10번], [2025 경원중 14번]
- **문제를 낸 이유**: 정오각형의 한 내각의 크기 유도와 대각선이 형성하는 이등변삼각형의 밑각 계산, 그리고 삼각형의 외각 성질을 유기적으로 융합하여 각도를 추론해내는 고난도 기하 능력을 측정한다.
- **[정답 풀이]**:
  1. 정오각형의 한 내각의 크기:
     $$\text{한 내각} = \frac{180^\circ \times (5 - 2)}{5} = \frac{540^\circ}{5} = 108^\circ$$
     따라서 $\angle ABC = \angle BCD = 108^\circ$이다.
  2. 삼각형 $ABC$를 보면, 정오각형의 변이므로 $\overline{AB} = \overline{BC}$인 이등변삼각형이다.
     따라서 밑각의 크기는,
     $$\angle BAC = \angle BCA = \frac{180^\circ - 108^\circ}{2} = \frac{72^\circ}{2} = 36^\circ$$
  3. 마찬가지로 삼각형 $BCD$를 보면, $\overline{BC} = \overline{CD}$인 이등변삼각형이다.
     따라서 밑각의 크기는,
     $$\angle CBD = \angle BDC = \frac{180^\circ - 108^\circ}{2} = 36^\circ$$
  4. 이제 삼각형 $PBC$를 관찰한다:
     - $\angle PBC = 36^\circ$
     - $\angle PCB = \angle BCA = 36^\circ$
  5. 구하고자 하는 각 $\angle APB$는 삼각형 $PBC$에서 꼭짓점 $P$의 한 외각이다!
     삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같으므로,
     $$\angle APB = \angle PBC + \angle PCB = 36^\circ + 36^\circ = 72^\circ$$
- **[오답 피하기]**:
  - ① $60^\circ$: 정삼각형의 한 각으로 막연히 추측하여 찍은 오답이다.
  - ④ $70^\circ$: $36 + 36 = 72$의 수치를 대략적인 십의 자리로 어림잡은 오답이다.

## 15번 해설
- **정답**: **③**
- **난이도**: [상]
- **원천 기출 연계**: [2025 도곡중 17번], [2025 충남여중 20번]
- **문제를 낸 이유**: 정사각형 내부에 형성된 4개 반원의 호가 겹쳐서 만들어지는 꽃잎 모양의 둘레를 구성하는 곡선들을 분해하여, 원주 공식과의 기하학적 일치 관계를 규명할 수 있는지 종합적으로 평가한다.
- **[정답 풀이]**:
  1. 색칠된 꽃잎 모양 4개의 둘레를 이루는 경계선은 무엇으로 이루어져 있는지 분해한다.
  2. 꽃잎 1개는 2개의 호로 둘러싸여 있으며, 꽃잎 4개는 총 8개의 호의 조각으로 구성된다.
  3. 정사각형의 네 변 $AB, BC, CD, DA$를 지름으로 하는 4개의 반원을 각각 그렸을 때, 각 반원의 호는 다른 두 반원의 호와 교차하면서 정확히 2개의 꽃잎 호를 형성한다.
  4. 따라서 색칠한 4개 꽃잎의 둘레의 총합은, **네 변을 지름으로 하는 4개 반원의 호의 길이의 총합과 완벽하게 일치한다!**
  5. 각 반원의 지름은 정사각형의 한 변의 길이인 $12\text{cm}$이다.
     반원 1개의 호의 길이는 지름 $12\text{cm}$인 원 둘레의 절반이므로,
     $$\text{반원 1개의 호의 길이} = \frac{1}{2} \times (2\pi \times 6) = 6\pi\text{cm}$$
     (또는 $\frac{1}{2} \times 12\pi = 6\pi\text{cm}$)
  6. 이러한 반원이 4개 있으므로, 색칠한 꽃잎 전체 둘레의 길이는,
     $$\text{둘레의 총합} = 6\pi\text{cm} \times 4 = 24\pi\text{cm}$$
- **[오답 피하기]**:
  - ① $12\pi\text{cm}$: 반원 2개의 호만 더하고 4개 전체를 고려하지 못한 오답이다.
  - ② $18\pi\text{cm}$: 반원 3개의 호의 합에 해당하는 오답이다.
  - ⑤ $36\pi\text{cm}$: 둘레 계산 시 내부 호의 중복을 과다 계상한 경우이다.
