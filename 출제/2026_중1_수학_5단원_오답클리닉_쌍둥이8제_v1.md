#### 문항 2번 상세 해설 (정답: ③)

#### 문항 3번 상세 해설 (정답: ③)
- 점 P, Q를 지나고 직선 l, m에 평행한 보조선을 각각 긋습니다.
- **점 P의 각도 분할**:
  - 위쪽 각 = l과의 엇각 = 30°
  - 아래쪽 각 = (3x - 15°) - 30° = 3x - 45°
- **점 Q의 각도 분할**:
  - 위쪽 각 = 점 P 아래쪽 각과의 엇각 = 3x - 45°
  - 아래쪽 각 = 직선 m과의 엇각 = x°
- **방정식 수립**:
  $$(3x - 45^\circ) + x^\circ = 95^\circ \implies 4x - 45 = 95 \implies 4x = 140 \implies x = 35$$
- **오답 방지 클리닉**: 꺾인 점이 2개일 때는 위아래 각을 엇각으로 전달하는 계단식 분할을 적용합니다.

#### 문항 7번 상세 해설 (정답: ⑤)
- **작도 순서**: 점 O 중심 호 그리기(㉠) $\to$ 점 A 중심 호 그리기(㉣) $\to$ 컴퍼스로 CD 재기(㉡) $\to$ 점 P 중심 호 그리기(㉤) $\to$ 반직선 AQ 긋기(㉢)
- **보기 판정**:
  - ㄱ. [참] 가장 마지막 단계는 두 점 A, Q를 지나는 반직선 AQ를 긋는 ㉢입니다.
  - ㄴ. [참] 점 O와 점 A에서 같은 반지름으로 컴퍼스를 벌렸으므로 $OC = OD = AP = AQ$입니다.
  - ㄷ. [참] 컴퍼스로 CD의 길이를 재어 점 P에서 옮겼으므로 $CD = PQ$입니다.
  - ㄹ. [참] $\triangle OCD \equiv \triangle APQ$ (SSS 합동)이므로 $\angle XOY = \angle PAQ$가 성립함을 증명할 수 있습니다.
- **오답 방지 클리닉**: 각 복사 작도는 SSS 합동 원리를 이용한 것이므로 모든 조건이 참입니다.

#### 문항 8번 상세 해설 (정답: ⑤)
- **합동 증명**:
  - 사각형 ABCD가 정사각형이므로 $AB = BC = 12$, $\angle B = \angle C = 90^\circ$
  - 조건에서 $BE = CF = 5$
  - 두 변의 길이와 그 끼인각이 같으므로 $\triangle ABE \equiv \triangle BCF$ (SAS 합동) [ㄱ 참]
- **대응변의 길이**:
  - 합동인 두 삼각형의 대응변이므로 $AE = BF$ [ㄴ 참]
- **수직 교차 증명**:
  - $\triangle ABE$에서 $\angle BAE = \bullet$, $\angle AEB = \times$라 하면 $\bullet + \times = 90^\circ$
  - 합동에 의해 $\angle CBF = \angle BAE = \bullet$
  - $\triangle PBE$에서 $\angle PBE + \angle PEB = \bullet + \times = 90^\circ \implies \angle BPE = 90^\circ \implies AE \perp BF$ [ㄷ 참]
- **오답 방지 클리닉**: 합동을 찾은 후 대응변($AE=BF$)은 당연히 참이므로 망설이지 않고 참으로 체크해야 합니다.
