[1단계: 작도 순서 검증]
점 O 중심 호(㉠) ➔ 점 A 중심 호(㉣) ➔ 선분 CD 길이 재기(㉡) ➔ 점 P 중심 호(㉤) ➔ 반직선 AQ 긋기(㉢)
따라서 가장 마지막에 수행하는 작도 과정은 ㉢이 맞습니다. (ㄱ 참)
[2단계: 선분의 길이 관계 판정]
• 점 O와 점 A에서 같은 반지름으로 컴퍼스를 벌려 그렸으므로 OC = OD = AP = AQ가 성립합니다. (ㄴ 참)
• 컴퍼스로 선분 CD의 길이를 재어 점 P에서 원호를 그려 교점 Q를 잡았으므로 CD = PQ입니다. (ㄷ 참)
[3단계: 이용된 합동 원리]
△OCD와 △APQ에서 세 대응변의 길이가 각각 같으므로 SSS 합동에 의해 ∠XOY = ∠PAQ가 성립합니다. (ㄹ 참)
[오답 탈출 Tip] CD = PQ 및 SSS 합동 원리를 놓치지 말고 끝까지 꼼꼼히 확인하세요!
문항 8번 상세 해설 (정사각형 내부 직각삼각형 합동) 정답: ⑤번 (ㄱ, ㄴ, ㄷ)
[1단계: △ABE 와 △BCF 의 합동 증명 (ㄱ 참)]
정사각형이므로 AB = BC = 12 cm, ∠B = ∠C = 90°이고, 조건에서 BE = CF = 5 cm입니다.
두 변의 길이와 그 끼인각이 각각 같으므로 △ABE ≡ △BCF (SAS 합동)입니다.
[2단계: 대응변의 길이 (ㄴ 참)]
합동인 두 삼각형의 대응변의 길이는 서로 같으므로 선분 AE와 선분 BF의 길이는 같습니다 (AE = BF).
[3단계: 두 선분의 수직 교차 증명 (ㄷ 참)]
직각삼각형 ABE에서 ∠BAE = •, ∠AEB = ×라 하면 • + × = 90°입니다.
합동에 의해 ∠CBF = ∠BAE = •이므로, 교점 P를 포함하는 △PBE에서:
