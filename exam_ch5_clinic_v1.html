문항 1번 상세 해설 정답: ②번 (ㄴ, ㄷ)
[개념 분석] 작도(Construction)는 오직 눈금 없는 자와 컴퍼스만을 사용합니다.
[보기 판정]
• ㄱ: [거짓] 눈금 없는 자에는 눈금이 없으므로 길이를 직접 잴 수 없습니다.
• ㄴ: [참] 컴퍼스로 길이를 재어 다른 직선으로 옮깁니다.
• ㄷ: [참] 두 점을 잇는 직선이나 연장선은 눈금 없는 자를 씁니다.
• ㄹ: [거짓] 각도기는 작도 도구에 포함되지 않습니다.
[오답 탈출 Tip] '각도기', '눈금으로 재기'는 작도 시험의 1순위 오답 함정 선지입니다!
문항 2번 상세 해설 정답: ③번 (8)
[1단계] 모서리 AB와 꼬인 위치 (x)
직육면체 모서리 총 12개 중:
- 만나는 모서리 (4개): AD, BC, AE, BF
- 평행한 모서리 (3개): CD, EF, GH
- 자기 자신 (1개): AB
따라서 x = 12 - (4 + 3 + 1) = 4개 (DH, CG, EH, FG)
[2단계] 면 ABCD와 평행한 모서리 (y)
면 ABCD와 만나지 않는 평행 밑면 EFGH의 네 모서리: EF, FG, GH, HE $\implies y = \mathbf{4}$개
[3단계] 계산 x + y = 4 + 4 = 8
[오답 탈출 Tip] 꼬인 위치 계산 시 평행한 모서리 3개를 누락 없이 제외해야 합니다.
문항 3번 상세 해설 정답: ③번 (35)
[1단계] 보조선 긋기
두 꺾인 점 P, Q를 지나며 l, m에 평행한 보조선을 긋습니다.
[2단계] 엇각을 이용한 계단식 분할
• 점 P 위쪽 각 = l과의 엇각 = 30°
• 점 P 아래쪽 각 = (3x - 15°) - 30° = 3x - 45°
• 점 Q 위쪽 각 = 점 P 아래쪽 각과의 엇각 = 3x - 45°
• 점 Q 아래쪽 각 = 직선 m과의 엇각 = x°
[3단계] 방정식 계산
(3x - 45°) + x° = 95° $\implies$ 4x = 140 $\implies$ x = 35
[오답 탈출 Tip] (3x - 15°) - 30°의 부호 계산 실수에 주의하세요.
문항 4번 상세 해설 정답: ②번 (ㄴ, ㅁ)
[보기 판정]
• ㄱ: [거짓] 5 + 6 = 11 < 12 (삼각부등식 불성립)
• ㄴ: [참] 두 변 AB, AC와 그 끼인각 ∠A가 주어짐 (SAS)
• ㄷ: [거짓 - 킬러 함정] AB, BC의 끼인각은 ∠B여야 함. ∠A가 주어지면 C가 2개 생겨 하나로 결정되지 않음!
• ㄹ: [거짓] 세 각만 주어지면 무수히 많이 결정됨.
• ㅁ: [참] ∠C = 180° - (40° + 65°) = 75°이므로 한 변 BC와 양 끝 각 ∠B, ∠C 확정 (ASA)
[오답 탈출 Tip] 두 변 AB, BC가 주어졌을 때는 공통 알파벳인 ∠B가 각으로 주어졌는지 반드시 확인하세요!

문항 5번 상세 해설 정답: ④번 (18)
[1단계] 서로 다른 직선의 개수 (x)
• 직선 l 위의 세 점으로 만드는 직선: 1개
• 직선 밖 두 점 P, Q를 잇는 직선: PQ ➔ 1개
• 점 P와 A, B, C를 잇는 직선: 3개
• 점 Q와 A, B, C를 잇는 직선: 3개
따라서 x = 1 + 1 + 3 + 3 = 8개
[2단계] 서로 다른 선분의 개수 (y)
5개의 점 중 서로 다른 2개를 택하는 조합:
y = (5 × 4) / 2 = 10개
[3단계] 계산 x + y = 8 + 10 = 18
[오답 탈출 Tip] 직선 l 자체(1개)와 두 외부점을 잇는 직선 PQ(1개)를 절대 누락하지 마세요!
문항 6번 상세 해설 정답: ②번 (ㄱ, ㄴ)
[직육면체 모델로 정밀 판정]
• ㄱ: [참] 한 평면에 수직인 서로 다른 두 직선은 평행합니다. (직육면체 기둥 모서리들)
• ㄴ: [참] 공간에서도 평행선 추이성은 항상 성립합니다.
• ㄷ: [거짓] 바닥면 P에 수직인 모서리 l은 옆면 Q에 포함될 수 있어 항상 평행하지 않습니다.
• ㄹ: [거짓] 기둥 모서리 l에 각각 수직인 가로 모서리 m과 세로 모서리 n은 서로 직교(m ⊥ n)합니다.
[오답 탈출 Tip] 공간 위치 관계 문제는 머리로 상상하지 말고 직육면체를 그려 모서리를 직접 대입하세요!
문항 7번 상세 해설 정답: ⑤번 (ㄱ, ㄴ, ㄷ, ㄹ)
[1단계] 작도 순서
점 O 중심 호(㉠) ➔ 점 A 중심 호(㉣) ➔ 선분 CD 길이 재기(㉡) ➔ 점 P 중심 호(㉤) ➔ 반직선 AQ 긋기(㉢)
➔ 마지막 과정은 ㉢이 맞습니다. (ㄱ 참)
[2단계] 선분의 길이 관계
• 점 O, A에서 같은 반지름으로 그렸으므로 OC = OD = AP = AQ입니다. (ㄴ 참)
• CD를 재어 점 P에서 원호를 그렸으므로 CD = PQ입니다. (ㄷ 참)
[3단계] 합동 원리
△OCD ≡ △APQ (SSS 합동)이므로 ∠XOY = ∠PAQ가 성립합니다. (ㄹ 참)
[오답 탈출 Tip] CD = PQ 및 SSS 합동 원리를 놓치지 말고 끝까지 꼼꼼히 확인하세요!
문항 8번 상세 해설 정답: ⑤번 (ㄱ, ㄴ, ㄷ)
[1단계] SAS 합동 증명 [ㄱ 참]
정사각형이므로 AB = BC = 12, ∠B = ∠C = 90°, 조건에서 BE = CF = 5
따라서 △ABE ≡ △BCF (SAS 합동)
[2단계] 대응변의 길이 [ㄴ 참]
합동인 두 삼각형의 대응변이므로 AE = BF입니다.
[3단계] 수직 교차 증명 [ㄷ 참]
△ABE에서 ∠BAE = •, ∠AEB = ×라 하면 • + × = 90°
합동에 의해 ∠CBF = •이므로 △PBE에서 ∠BPE = 180° - (• + ×) = 90° ➔ AE ⊥ BF
[오답 탈출 Tip] 합동을 증명했다면 대응변의 길이(AE = BF)는 당연히 참으로 체크해야 합니다!
